Architecture et Interface Utilisateur (UX)

Conception et développement intégral d'une application Android (Java) permettant de lire, stocker et dupliquer des badges RFID/NFC Mifare Classic en communiquant avec un lecteur matériel externe (RC522) via un protocole série.

Le défi : L'Expérience Utilisateur (UX)

L'enjeu technique principal de ce projet n'était pas la lecture NFC en elle-même, mais la gestion de l'asynchronisme matériel. Les opérations de balayage cryptographique des clés Mifare par le capteur prennent un temps variable (latence). Si l'interface attend de manière séquentielle, l'application se bloque ("freeze"), générant une mauvaise expérience utilisateur.

La solution : State Machine Asynchrone

Pour garantir la fluidité de l'interface, j'ai développé une architecture basée sur une Machine à États (State Machine). Le processus matériel tourne sur un thread séparé (Back-end) qui communique en permanence avec l'IHM (Front-end) pour afficher la progression en temps réel sans jamais figer l'écran.

Stack Technologique

Java Android Studio UX/UI Asynchrone UART / RC522 RFID / Mifare

🌍 APPLICABILITÉ INDUSTRIELLE

Le pilotage logiciel de capteurs lents ou asynchrones (comme une caméra scientifique ou un scanner 3D) requiert systématiquement ce type d'architecture IHM (C++/Qt ou Java) pour assurer une supervision fluide.
