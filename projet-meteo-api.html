Architecture de la solution

Développement d'un dashboard de supervision télémétrique en JavaScript asynchrone ("Vanilla JS"). Ce client léger orchestre dynamiquement les protocoles d'acquisition réseau via l'API Open-Meteo et la géolocalisation native du navigateur. Des mécanismes de fallback ont été intégrés pour garantir l'affichage continu (mode dégradé) en cas de défaillance des endpoints.

Compétences démontrées

Intégration d'API REST, maîtrise du routage asynchrone (Promises/Async-Await), gestion active des erreurs de réseau (Timeout, Code HTTP), et restitution optimisée de la donnée brute.

Stack Technologique

JavaScript ES6 Fetch API Geolocation API JSON / REST

Application industrielle

La remontée sécurisée d'informations est le concept fondateur de toute plateforme d'hypervision (salles de contrôle industrielles, SCADA ou tableaux de bord Cloud). Extraire un flot de métriques, filtrer la latence réseau, et modéliser visuellement la data utile est indispensable au monitoring d'infrastructures.
